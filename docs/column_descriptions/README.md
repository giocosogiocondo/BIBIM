# English IFC descriptions

These offline catalogs are derived from IfcOpenShell 0.8.5's bundled buildingSMART documentation and schemas. Entries retain source URLs and description methods. `source_manifest.json` records upstream inputs; `validation.json` pins the distributed schema catalogs. Database-specific mappings and validation coverage from private experiments are excluded.

The catalogs describe schema semantics, not whether a property exists in a particular model. Custom and ambiguous fields are not assigned invented official definitions. The root usage guide explains how to rebuild the catalogs.
